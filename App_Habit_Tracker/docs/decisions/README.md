# Decisiones de arquitectura (ADR)

Cada decisión importante queda en un archivo corto con el formato: contexto, decisión, alternativas y consecuencias. Un ADR en estado **Propuesta** pasa a **Aceptada** cuando se fusiona la PR que lo trae. Si una decisión cambia, se escribe un ADR nuevo que reemplaza al anterior. Los antiguos no se editan, con dos excepciones: marcarlos como reemplazados, o cerrar un punto que quedó pendiente, en una sección "Actualización" con fecha.

Las fechas van en formato DD-MM-AAAA. Cada ADR lista las fuentes que se consultaron, con la fecha de consulta.
